## 两个易混淆点

1. **说法不一致 ≠ 有人在撒谎**:拆成事实 / 观点 / 利益诉求三层;客户本身的分歧如实保留,本周不要求查明真相。
2. **模型加载了业务知识 ≠ 客户问题解决了**:用同题对照(有/无业务模型)+ 实际请求记录证明 Agent 真的用上了,而非靠常识答对。
