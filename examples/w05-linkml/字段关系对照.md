# 独立业务与字段关系对照

| 原业务说法 | classes.slots 应包含 | 技术定义已提供 | 来源和仍需判断 |
| --- | --- | --- | --- |
| 统一业务对象或明确未决桶 | Member: id, identity_status | 字符串标识、枚举、必填 | 实名依据由 Python；桶不称自然人 |
| 姓名可未知 | Member: display_name | 可空字符串 | 缺失和冲突由属性函数 |
| 一个对象多个来源账户 | Member: source_accounts | SourceAccount 类型、多值引用 | 有效身份依据；弱相同不合并 |
| 多个注册门店 | Member: registered_stores | Store 类型、多值引用 | 来源 CRM 注册关系；不能用购买门店 |
| 账户来源与未知关系 | SourceAccount: id, system, source_file, source_row, registered_store | 必填来源、行号整数>=1、门店可空 | 原文件／去表头行号；POS 无注册关系 |
| 门店标识与名称 | Store: id, name | 字符串主键和必填名称 | 已接受门店表 |
| 旧复杂字段保留 | Member 和 SourceAccount: payload | 底座维护 JSON 字符串 | 内部客户语义仍由 Python／既有契约维护 |

生成器产生字段和链接结构；有效身份证据、归属唯一性、注册来源一致性、联系限制不由 description 自动执行。固定核心字段要求是本候选供给接口，学员不能删掉底座正在提供的字段来绕过业务信息。
