# 测试数据字典

覆盖：2024-09-01（包含）至 2026-09-01（不包含），Asia/Shanghai，日期粒度。数据是干净合成测试集，不是原始 CRM；账户不等于跨系统自然人。

## orders

一行一笔订单

| 字段 | 含义 |
| --- | --- |
| order_id | 唯一订单号 |
| member_id | CRM 会员账户 ID，关联 members.member_id |
| store_id | 订单成交门店 ID，关联 stores.store_id；不等于会员归属门店 |
| ordered_at | 下单本地日期，Asia/Shanghai；date |
| status | paid 或 cancelled |
| gross_cents | 原价金额，整数分 |
| paid_cents | 实付金额，整数分；取消为零 |
| refund_cents | 截至数据快照的累计退款，整数分，不能大于实付 |
| quantity | 该订单原始购买件数，正整数 |
| channel | 门店或小程序 |

## members

一行一份 CRM 会员账户

| 字段 | 含义 |
| --- | --- |
| member_id | 账户主键，不视为跨系统自然人 ID |
| registered_at | 账户注册本地日期 |
| home_store_id | 会员归属门店，关联 stores.store_id |
| tier | 普通、银卡或金卡 |

## stores

一行一间门店

| 字段 | 含义 |
| --- | --- |
| store_id | 门店主键 |
| region | 华东、华南或华北 |
| store_name | 门店名称 |

## cards

一行一张会员卡，账户可对应多张卡。这里只解释物理字段，不裁定本期业务口径纳入哪些卡。

| 字段 | 含义 |
| --- | --- |
| card_id | 卡主键 |
| member_id | CRM 账户外键，关联 members.member_id |
| card_type | 产品名称枚举：悦享年卡、家庭季卡、异业联名卡、体验卡；业务纳入范围见客户确认 |
| valid_from | 权益开始日期，date |
| valid_until | 计划权益结束日期，date；端点如何解释见业务规则 |
| ended_at | 提前终止日期，date，可为空 |
| card_paid_cents | 购卡实付分；此值不等于商品订单收入，也不直接裁定资格 |

## 课程方提供的数据接入层

members、stores、cards、orders 原样接入上述 CSV，不附加业务规则或派生列。time_spine 按 manifest 的覆盖起止日生成，结束日不含。语义模型、带业务规则的排序和汇总、资格判定由学员 Skill 根据业务模型、客户资料和本字典生成；内部模型名称由学员选择。
