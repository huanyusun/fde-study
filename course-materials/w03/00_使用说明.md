# W03 材料包：把客户口径接入运营 Agent

本周承接 W02 业务模型，补充调查并更新模型，开发指标构建与校验能力，让已升级的运营 Agent 按青禾口径查数，并带着证据确认阶段范围。

版本：`w03-0.1.0`。先读 [作业任务书](05_作业任务书.md)，再按工程包 README 准备环境。第一次做先看任务书的“作业路线”，出错查文末“报错对照表”。

运营 Agent 继续使用原聊天入口，本周新增自然语言查数能力。访谈仍在原客户访谈服务，按账号的 W03 开放状态进入；服务地址与账号由课程方随班期通知提供。模型 API 使用自己的配置，不要求自备 coding Agent。

本包为虚构课程材料和合成测试数据。初始包不包含青禾最终指标库、完整指标核定记录、W03 标准业务模型或教师测试答案。必要时由课程方直接分发本周关键原始事实的兼容 JSON 与同源 MD；不经 Agent 领取，不提供完成模型。W02 的参考答案见 [W2 checkpoint](W02_checkpoint/README.md)，照抄不算完成 W02；W03 的 checkpoint 随 W04 材料包提供。具体使用规则见任务书。
