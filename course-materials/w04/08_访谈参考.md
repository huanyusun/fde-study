# W04 访谈参考（选看）

> 这份参考是给第一次做 2B 访谈的同学搭一座桥：课上讲了方法，这里看方法怎样变成一句问得出口的话。不看也不影响作业，不增加作业要求，也不是批改依据。

不要照着念。本周手上第一次有了客户的原始数据，访谈的方式也变了：先剖析，再带着看到的东西去问。发给模型的内容只放回答所需的汇总和定义，不放会员姓名、手机号和工作账内容。

## 一、一场访谈怎样走

| 环节 | 要做到什么 | 可以这样说 |
| --- | --- | --- |
| 说来意 | 说清这次要核实哪几行 | 我剖析了这份导出，有几处和字典对不上，想请您看看 |
| 摆出看到的 | 先说数据里的现象，不先说结论 | 这个字段字典写的是这样，导出里实际看到的是这样 |
| 问含义 | 请对方解释，不替对方下结论 | 这种写法是什么意思？平时是谁在填？ |
| 说清要什么 | 说明这条要用来做什么 | 我要据此写清洗规则，想确认这一点 |
| 问边界 | 确认规则到哪里为止 | 这两种情况要怎样区分？ |
| 复述确认 | 分清已确认和待核 | 我记成这样，对吗？这一项还要找谁核实？ |

## 二、同一个意图，换一种问法

| 容易这样问 | 可以这样问 | 为什么 |
| --- | --- | --- |
| 字典里每个字段都是什么意思？ | 这几个字段实际值和字典不一致，先问这几个 | 带着差异问，不按字典逐项问 |
| 数据质量怎么样？ | 我统计到这个字段有这几种写法，您看哪些是正常的？ | 具体现象才答得出来 |
| 这份数据有没有问题？ | 这几条我打算隔离不导入，您看这样处理合适吗？ | 说出处理打算，对方才能给意见 |
| 我猜这是录入错误，对吧？ | 这种记录是怎样产生的？ | 不把自己的推断塞进对方嘴里 |
| 帮我把清洗规则写一下 | 我按这条理解写规则，有没有例外？ | 规则由你来写，对方核实依据 |
| 所有规则都是这样吗？ | 刚才您说的这条，到这种情况还适用吗？ | 用边界例子试，发现说法里过于绝对的地方 |

这是一组例子，不是必问清单。对方说这次先不展开，就记成待核项，不要反复追同一句。

## 三、一段带批注的示范

下面节选自课程方的一次测试访谈，**问**是访谈者，**答**是小林。你问时小林的回答不一定相同，不要拿这段当核实依据。

为了不替你给出答案，具体的标签和备注规则都用「……」略去，这里只看怎样问、怎样接。

**问**：小林，我看到 tag 不只是字典的12个标签：……请确认现用标准标签完整清单、新增标签的含义，以及怎样分辨标签和一整条备注……哪些触达限制写法必须认出来？我只问规则，不发会员个人信息或工作账明细。

**答**：……字典里没有，具体含义得结合实际填写再核。……

> 批注：开口先摆出剖析看到的现象，再问要确认什么，最后说明不发个人信息。对方说「得结合实际填写再核」的部分，不能记成已确认。

**问**：……请明确：同一字段什么时候可判为两条备注……什么时候逗号只是备注内部？……避免漏识别或把普通联系状态当禁止触达。

**答**：……其他语义限制写法得结合实际填写再核……勿扰名单和系统标签两边我没核对过，不一定一致。

> 批注：第二问拿具体写法追边界，还说清了担心什么错。回答末尾多出一条线索：两边没核对过。这正好可以接到诊断报告的工作账对照。

**问**：需要再确认一个边界：……请明确实际写法规则，未知的边界我会申请课程方同源事实补充，不猜。另请确认工作账只是独立快照，勿扰对照差异只能作为待核项。

**答**：我前面说「整条备注里的逗号都不拆」，这话说得太绝对了，得更正一下。……完整的切分语法我这边并不掌握……都还需要核实……工作账是每周一拉报表后独立填的，算独立快照；勿扰名单和系统标签两边我没核对过，差异只能先当待核项。

> 批注：这一轮最值得看。拿一个反例回去问，对方更正了自己前面的说法，也说出了哪里不掌握。记录时前后两句都留着，写明以哪句为准；「不掌握」要记下来，不要用猜测补上。

## 四、问完怎样记

数据看出来的和访谈听来的分开记，诊断报告才站得住。

| 记成什么 | 例子 | 怎么用 |
| --- | --- | --- |
| 数据结论 | 某字段有几种写法，各多少行 | 写明统计方法，数字来自自己的产出文件 |
| 访谈依据 | 小林：某条说法，并注明记录位置 | 说明是谁说的；前后有更正的，写明更正 |
| 我的推断 | 这批记录可能属于某一类 | 写明是推断，不写成客户确认 |
| 待核项 | 两边名单差异未核对 | 写下一步找谁、要什么依据 |

访谈后回到第 4 步的表格，把「待访谈」的行改成核实结果。

## 五、访谈老周、陈姐时怎样用

这里不列问题，先自己想清楚三件事：

1. 第 4 步的表里，哪几行要核实，这个人的职责能不能回答。
2. 你手上的剖析结果是什么，能不能先把现象摆出来。
3. 拿到回答以后，它会改变哪一条清洗规则或模型判断。

想清楚再开始，问法参考第二节，方法细节回看 V03。
