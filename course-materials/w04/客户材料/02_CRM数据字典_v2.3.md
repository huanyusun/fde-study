# CRM 数据字典 v2.3

编写：信息技术部
版本：v2.3
更新日期：2023-05-26

本字典说明新 CRM 会员数据的字段含义，供数据使用方参考。

## 会员表（crm_member_export）

一行一个会员。

| 字段 | 名称 | 类型 | 说明 |
| --- | --- | --- | --- |
| `hy_id` | 会员号 | 文本 | QH 加 8 位数字，唯一 |
| `nm` | 姓名 | 文本 | |
| `mobile` | 手机号 | 文本 | 11 位 |
| `birth` | 生日 | 日期 | 可为空 |
| `join_dt` | 注册日期 | 日期 | 会员注册的日期 |
| `lv` | 会员等级 | 代码 | 1 普通，2 银卡，3 金卡 |
| `stat` | 会员状态 | 代码 | 1 正常，2 冻结，3 注销 |
| `src_ch` | 注册渠道 | 文本 | 门店、小程序、商城 |
| `reg_shop` | 注册门店 | 文本 | 门店编码，4 位数字，见门店表 |
| `tag` | 会员标签 | 文本 | 多个标签用逗号分隔，取值见附录标签表 |

## 订单表（crm_order_export）

一行一笔订单。

| 字段 | 名称 | 类型 | 说明 |
| --- | --- | --- | --- |
| `ord_no` | 订单号 | 文本 | 唯一 |
| `hy_id` | 会员号 | 文本 | 见会员表 |
| `shop_cd` | 成交门店 | 文本 | 门店编码，见门店表 |
| `ord_tm` | 下单时间 | 日期时间 | |
| `ord_stat` | 订单状态 | 文本 | 已支付、已完成、部分退款、全额退款、已取消 |
| `amt_total` | 原价金额 | 整数 | 单位：分 |
| `amt_pay` | 实付金额 | 整数 | 单位：分 |
| `amt_rfd` | 累计退款金额 | 整数 | 单位：分 |
| `qty` | 件数 | 整数 | |
| `ch` | 渠道 | 文本 | 门店、小程序、商城 |

## 会员卡表（crm_card_export）

一行一张卡，一个会员可以有多张卡。

| 字段 | 名称 | 类型 | 说明 |
| --- | --- | --- | --- |
| `card_no` | 卡号 | 文本 | 唯一 |
| `hy_id` | 会员号 | 文本 | 见会员表 |
| `card_kind` | 卡种 | 文本 | 悦享卡（年）、家庭季卡、异业联名卡、体验卡 |
| `st_dt` | 生效日期 | 日期 | |
| `ed_dt` | 到期日期 | 日期 | |
| `stop_dt` | 提前终止日期 | 日期 | 可为空 |
| `pay_amt` | 购卡实付 | 整数 | 单位：分 |

## 门店表（crm_shop）

一行一家门店。

| 字段 | 名称 | 类型 | 说明 |
| --- | --- | --- | --- |
| `shop_cd` | 门店编码 | 文本 | 4 位数字，唯一 |
| `shop_nm` | 门店名称 | 文本 | |
| `area` | 大区 | 文本 | 华东、华南、华北 |
| `open_dt` | 开业日期 | 日期 | |
| `shop_stat` | 门店状态 | 文本 | 营业、闭店 |

## 附录：标签表

| 标签 | 含义 |
| --- | --- |
| 高价值 | 近一年消费金额居前的会员 |
| 价格敏感 | 主要在促销期购买 |
| 宠物 | 购买宠物用品 |
| 生鲜偏好 | 生鲜品类消费占比高 |
| 母婴-0到3岁 | 家有 0～3 岁婴幼儿 |
| 母婴-3到6岁 | 家有 3～6 岁儿童 |
| 周末家庭 | 以周末家庭采购为主 |
| 学生 | 学生会员 |
| 企业团购 | 有企业团购记录 |
| 流失预警 | 消费频次明显下降 |
| 积分达人 | 积分兑换活跃 |
| 门店偏好 | 主要在门店购买 |
