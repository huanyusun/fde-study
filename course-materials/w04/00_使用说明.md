# W04 材料包：把客户的原始数据接进标准产品

本周老周交来了新 CRM 的原始导出。你要先剖析这份数据、核实它和字典及大家的说法哪里不一样，再清洗、隔离、导入青禾查询库并对账，按证据修订业务模型和指标定义，让 W03 的指标在客户原始数据上运行；然后按数据的实际情况选第一个 demo，在导入后的库上实际跑通，并如实记录 bad case。

工作账窗口以每条拉名单日期为准，不使用当前运行日期。

版本：工程 `fde-agent-w04-0.1.0-e15-c4`，数据 `qinghe-w04-v1.1`。先读 [作业任务书](05_作业任务书.md)，再按工程包说明准备环境。第一次做先看任务书的“作业路线”，出错查文末“报错对照表”。

**数据规模**：本周数据按真实业务规模的 1／10 缩小。客户口中的数字是全量说法，比如老周说的 120 万个账户，在这份数据里约为 12 万个；你算出的结果乘以 10 之后与客户的说法大致相当即可，不必凑成整数。批改以这份数据的实际值为准。

**起点**：本周承接你 W03 的业务模型、查询库和指标库，保留原版，在 W04 副本上继续核实和修订。没有完成 W03 的，可以使用材料包中的 [W03 checkpoint](W03_checkpoint/README.md)：其中包含业务模型和可加载的指标库，在副本上继续修订即可，并在提交中注明采用了哪些部分。参考状态不能当作本人成果，照抄不算完成 W03。

**环境**：Python 3.11 或更新版本，安装步骤见工程包根目录的 README。下载新版本 Python 失败时，用本机已有的 3.11 以上版本即可。

**访谈**：仍在原客户访谈服务，按账号的 W04 开放状态进入，服务地址与账号随班期通知提供。运营 Agent 继续使用原聊天入口；模型 API 使用你自己的配置，不要求自备 coding Agent。

本包的青禾客户材料为虚构课程材料，业务数据为合成数据；两张案例卡依据外部项目分享整理，来源归属、教学分析和未披露信息分别见卡内说明。包内不含青禾的清洗答案、字段映射答案、标准剖析结果或教师测试样本。关键事实访谈不到时，课程方可以直接分发同源的事实补充。W04 的 checkpoint 随 W05 材料包提供。具体规则见任务书。
