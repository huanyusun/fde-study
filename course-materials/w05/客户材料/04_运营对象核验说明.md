# 青禾优选：运营对象核验说明

> 业务依据说明 v0.1｜2026-10-08。适用于本轮会员运营推荐；配套核验记录随数据包交付，不表示所有账户均已核验。

## 一、核验记录与适用范围

本轮不向经证据确认的员工、异常身份提出运营联系建议。这里的“确认”来自业务核验记录，不能仅凭注册集中、姓名相似、没有订单等现象判断。

配套记录按来源账户提供核验对象、核验依据及来源位置、结论、确认时间、状态和适用范围。依据应说明核对了什么，例如员工登记资料或注册复核记录；仅有一个没有来源的“异常”标签不足以支持判断。

| 记录情况 | 本轮处理 |
| --- | --- |
| 有效记录确认员工身份 | 通过已核实的身份关系作用于该会员，本轮不推荐联系 |
| 有效记录确认异常注册身份 | 在记录指定的账户或身份范围内排除运营推荐，保留原因及依据 |
| 只有疑似线索、记录未完成或有效依据冲突 | 保留待核，不自动升级成已确认排除，也不当作已确认正常 |
| 没有发现核验记录 | 只能说明现有材料中没有相应记录；结合声明的覆盖范围判断是否还有缺口，不声称已经证明其不是员工或异常对象 |

异常如果只针对一个来源账户，不能不经判断就给所有关联对象贴上相同结论。记录涉及“同一会员”的结论也必须建立在身份关联已核实的基础上。身份或适用范围未决时，应同时说明影响。

## 二、推荐与经营统计分别处理

运营排除不删除会员、账户或订单，也不自动扣减原经营指标。员工私人购买等记录仍按已核定的支付及退款口径参与相应经营统计。

结果应能区分符合消费和沉睡条件的人、因明确业务依据排除的人，以及尚不能作出判断的人。不要把符合筛选条件的人数直接称为可联系人数。

本说明只确定本轮运营推荐的处理，不替代全公司会员总量、交易人数的核查口径。

## 三、遇到缺口怎样沟通

核验材料的来源、账户引用、有效状态或覆盖范围不清楚时，向老周核查；结论用于本轮运营的范围不清楚时，向小林核实。记录已有明确答案的部分直接使用，不重复申请确认。
