# 青禾优选：联系限制与建议说明

> 业务依据说明 v0.1｜2026-10-08。用于固定参考日 2026-09-01 的本轮分析和建议；原文、补充确认记录及各自版本共同构成依据，不授权执行联系。

## 一、怎样使用 CRM 备注与勿扰工作账

CRM 备注和小林勿扰工作账均需保留来源位置。旧工作账只有会员号、原因和登记日期，“本人要求”“投诉”“其他”这些原因本身不能说明限制了哪个渠道。

本轮通过补充确认记录说明具体条目的渠道范围。确认记录应指向原条目，保留原文、来源账户、确认依据、渠道范围、确认时间及状态；不修改原工作账来制造过去已经写明的含义。无法确认的条目继续待核。

| 已取得的有效依据 | 本轮含义 |
| --- | --- |
| 明确“请勿再联系” | 限制本轮所有联系渠道 |
| 明确“勿打电话” | 限制电话；不能由此推定其他渠道已获许可 |
| 明确“勿发短信” | 限制短信；不能由此推定其他渠道已获许可 |
| 只有勿扰原因，没有明确渠道或补充确认 | 限制范围待核，不能直接推荐通过某个渠道联系 |

在身份已核实的前提下，各来源限制合并生效。电话限制与短信限制可以同时成立；一处“可以联系”、空白备注或较新日期，不自动取消另一处仍有效的限制。本轮没有自动解除限制的规则。

用户未指定渠道时，分别返回已知限制和待核范围，不默认电话。存在明确禁止时保留禁止结论；另有不明范围时一并说明，不能把禁止降为待核，也不能把待核解释成许可。

## 二、怎样形成有依据的建议

| 会员当前上下文 | 可以给出的分析或建议 |
| --- | --- |
| 身份已核实、满足本轮条件，必要依据齐全且指定渠道未发现适用限制 | 说明消费和最近购买依据，列为供业务人员复核的联系候选；“未发现限制”不表述为已取得授权 |
| 旧 POS 有近 60 天有效购买，合并后不满足沉睡条件 | 说明已覆盖的近期购买，不能继续按沉睡会员推荐召回 |
| 明确限制联系，或确认属于本轮排除对象 | 说明不能推荐的具体依据，不提供绕过限制的联系方法 |
| 身份、覆盖、核验或限制范围未决 | 说明还缺什么、影响哪个判断及应向谁核实，暂不确认适合联系 |

业务说明用于结合实际会员上下文解释判断；只有通用策略文字，没有该会员的事实支持，不足以形成建议。回答应引用实际记录和本说明的适用条款及版本。即使没有合适联系对象，也可以给出核查或补数建议，不必编出一次营销动作。

本轮不提供优惠券、折扣、卡到期或效果承诺，不自动发券、发消息或写标签。执行方案由业务人员另行确认。

## 三、哪些问题需要补充沟通

材料中已经明确的规则可以直接使用。具体记录的渠道范围仍不清楚、多个账户限制存在冲突或出现本说明未覆盖的运营例外时，带来源记录向小林核实；账户是否属于同一会员的问题向老周核实。确认记录可以消除歧义，不能代替会员名单的实际计算。
