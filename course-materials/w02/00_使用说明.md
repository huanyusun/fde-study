# W02 材料包使用说明

> 材料版本：`w02-materials-0.3.7`，配套工程包 0.5.4。访谈开放窗口以班期通知为准。青禾优选、人物、旧项目材料及青橡图书馆示例均为虚构教学材料。

本周通过多角色访谈形成有依据的业务模型，再让 Agent 使用。本页提供导航；具体任务、提交与判定标准见[作业任务书](05_作业任务书.md)。

## 阅读顺序

1. [旧项目阶段结项 PPT](01_智能营销平台项目阶段结项汇报.pptx)与[背景补充](02_旧项目背景补充.md)：找出需要核实的问题。
2. [本周访谈对象](03_本周访谈对象.md)：了解角色，接续 W1 的问题。
3. [作业任务书](05_作业任务书.md)：按 5 个步骤完成访谈、提取、核查建模、Agent 验证和当前判断。
4. [访谈与核查记录模板](06_访谈与核查记录模板.md)、[业务模型说明模板](07_业务模型说明模板.md)：两份人工文档的可选起点；干系人地图写在访谈记录中。

[C02 AIG 案例卡](案例手册/C02_AIG.md)配合 V03 阅读，其中青禾课后对照为选做，不增加提交项。公开事实、教师分析与教学虚构分别标明。

## 工程与教学示例

[标准 Agent 工程包 0.5.4](工程/fde-student-w02-0.5.4.zip)提供持续提取工作流、自然语言业务模型加载、同题对照、自动记录及预检。解压后从 `docs/w02_walkthrough/README.md` 开始；安装和各命令说明均在包内；模型选择、普通慢请求的等待配置，以及访谈网页与本地工具的恢复区别，见工程内 `docs/model-configuration.md`。两份模板与本目录保持一致。V05 的持续提取入口见包内 `docs/w02_workflow/README.md`：Skill 保存方法，Agent 调用工具，学员逐组核查并确认模型修改。配置的模型须支持原生工具调用，密钥沿用环境变量。

W02 的辅助抽取、核查反馈、业务模型生成／更新和确认保存均通过终端命令操作。浏览器打开的本地 `report.html` 是只读报告，用于查看候选信息、原文和模型修改；具体命令见上述工作流说明。

图书馆示范已随同一个工程包提供：原始材料在 `examples/w02_extraction/`，持续提取起始材料及操作在 `examples/w02_workflow/README.md`，后续业务知识接入示范在 `examples/w02_natural/README.md`。用于 V04～V06 的方法示范和环境检查，不增加一套必交作业。示例请另解压一份工程包运行，不在自己的青禾工作目录中运行，以免示例配置占用青禾的知识配置。

正式任务仍使用自己的青禾访谈。业务模型中的重要图示应同时用文字说明，当前程序读取 Markdown 文字，不识别图片中的定义。

## 模型配置与运行限制

工具默认提供 8192 token／90 秒，确认输出预算截断后，临时以 16384 token／180 秒重试同一模型请求一次；再次失败则报错。`deepseek-json` 配置显式开启低强度推理，其他模型按接口选择配置。持续工作流保留推理续接所需的私有数据，公开记录保留每次调用的结束原因、追踪编号和已知用量。配置、恢复和更换模型的适配边界见工程内 `docs/model-configuration.md`。

访谈者的提问不代表其主张，“提问＋不知道”本身不构成分歧；没有答案的内容保留为未知，每轮候选仍须核查。

可修改课程工具的提示词、Skill 或必要代码，也可借助 coding Agent 开发自己的 Skill；两条路线均需实际运行、验证与本人核查，详见任务书。Windows、Linux 如遇问题，请反馈给课程方。
