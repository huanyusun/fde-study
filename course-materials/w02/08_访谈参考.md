# W02 访谈参考（选看）

> 这份参考是给第一次做 2B 访谈的同学搭一座桥：课上讲了方法，这里看方法怎样变成一句问得出口的话。不看也不影响作业，不增加作业要求，也不是批改依据。

不要照着念。访谈的价值在于沿着对方刚说的话往下问，同样的问题换个人、换个时机就不合适了。提问次数有限，先想清楚这次要弄明白什么。

## 一、一场访谈怎样走

| 环节 | 要做到什么 | 可以这样说 |
| --- | --- | --- |
| 说来意 | 让对方知道你是谁、为什么找他、结果怎么用 | 我在了解会员运营的实际做法，想看助手能帮上哪一步。今天想请您讲讲日常工作 |
| 问职责边界 | 分清哪些事对方能定，哪些要找别人 | 这块您主要负责什么？哪些事不是您一个人说了算？ |
| 落到一件具体的事 | 从概括说法落到实际经过 | 能不能拿最近一次，从头讲一遍？ |
| 沿回答追问 | 从对方的话里找下一问 | 您刚才说这一步最费力，具体费力在哪里？ |
| 问依据和看法 | 分清亲身经历、个人判断和可核对的记录 | 您这个判断是从哪里看出来的？ |
| 收尾 | 留下下一步 | 这件事还应该找谁核实？ |

## 二、同一个意图，换一种问法

| 容易这样问 | 可以这样问 | 为什么 |
| --- | --- | --- |
| 你们的业务流程是什么？ | 一项会员运营任务，从接手到收尾，您通常怎样一步步做？ | 有起点和终点，对方容易讲 |
| 给我看一下你们的记录 | 能不能拿最近一次回访，从头讲一遍？ | 访谈里看不到表格，请对方讲经过才问得出东西 |
| 复购率怎么算？（问所有人） | 先问清谁管这个口径，再问他 | 不是每个人都掌握，同一句「要核实」不用收集五遍 |
| 你们用什么系统、哪边是主数据、取数走接口吗？ | 我想核实会员数，用来给复购率定分母。您看到的数是什么范围？需要谁配合？ | 带着用途和具体问题，对方才知道该讲什么 |
| 你觉得系统好用吗？ | 上一次用它做事，是怎样用的？哪一步最费事？ | 从感受落到一件事 |
| 复购下滑的原因是什么？ | 您是从哪里看到下滑的？您判断的依据是什么？ | 原因不一定有人知道，先把说法和依据分开 |
| 您刚才说的那个问题……（对方其实没说过） | 先复述对方的原话，再往下问 | 把自己的推断说成对方的话，记录就错了 |

以回访为例，一次具体的事可以这样问下去：名单是怎么来的？多久没买算这一类？这些信息记在哪里、记些什么？为什么记在那里？哪一步最费时间？最后怎样判断这次回访有没有用？

这是一组例子，不是必问清单。对方说先不展开、要看记录才能确认，就记成待核项，换下一个问题，不要反复追同一句。

## 三、一段带批注的示范

下面节选自课程方的一次示范访谈，**问**是访谈者，**答**是小林。你问时小林的回答不一定相同，不要拿这段当核实依据。

**问**：林经理您好。先请您说说，会员运营这块您主要负责哪些工作？哪些事不是您一个人说了算？

**答**：我主要负责整理会员运营任务、准备活动安排，协调线上和门店执行，跟进进度、收集反馈……活动费用、跨部门资源、项目验收和合同这些，不是我一个人说了算，得找相应负责人确认。

> 批注：第一问同时问了能定什么、不能定什么，一下就有了干系人地图的素材。这句可以记进地图的「实际权限」。

**问**：一项会员运营任务，从接手到收尾，您通常是怎么一步步做的？

**答**：我通常先看没做完的运营任务和反馈，明确这次面向哪些会员、准备做什么，再和相关同事确认线上或门店的执行安排。执行时记录进度和问题，结束后整理反馈……

> 批注：这里拿到了工作环节。还只是通常做法，下一问就要落到一件具体的事。

**问**：能拿一次会员优惠券活动来具体说说吗？面向谁、怎么定执行方式、和谁协作，后面怎么跟进？

**答**：会员优惠券活动我确实经手，不过只能按这类活动的通常做法讲，不能把哪一次当成现成例子；具体某次的面向人群、日期和效果数字，都得查对应记录……发放和核销是两个环节，发放记录替代不了核销记录。

> 批注：对方没给具体的一次，不用硬追，把这句限定记下来：这是通常做法，不是某次已发生的事。答案里的「发放和核销是两个环节」是新线索，可以写进模型，再向老周核实记录。

**问**：这些工作里，哪些环节让您觉得最费力？大概花多少时间，您有量过吗？

**答**：最费力的是整理名单和执行记录、找同事确认对不上的信息，还有反复跟进进度。具体花多少时间我没量过，给不出时间数字。

> 批注：问时间很有用。「没量过」本身就是要记的信息：这是她的感受，不是测量结果，后面不能写成「整理名单占用了大量时间」的已知结论。

**问**：您刚才说整理名单费力。您平时说的「会员」是指哪些人？沈总提到按 80 万活跃会员来看，IT 那边说系统全量是 120 万，您做名单时用的是哪种范围？

**答**：我说的「会员」得先分清楚：一种是付费会员卡，一种是免费注册会员……名单范围我不直接拿活跃会员数或系统全量来当，而是看这次任务面向哪类会员、要做什么，再定这次圈哪部分人。80 万活跃会员和 120 万系统全量这两个数，各自怎么算、统计到哪一步，我目前没法确认，得核实。

> 批注：这一问做得最好的地方，是从「整理名单费力」接到「名单用什么范围」，又把另外两位的说法带来核对。注意她只是复述了这两个数，不能算成她对会员数的说法。

## 四、问完怎样记

把同一段话分开记，业务模型和访谈记录才站得住。

| 记成什么 | 例子 | 怎么用 |
| --- | --- | --- |
| 本人说法 | 小林：整理名单和执行记录最费力，没量过时间 | 写明是谁说的，引用记录位置 |
| 通常做法 | 小林：工作环节是面向谁、做什么、确认执行、记录进度、整理反馈 | 当工作方式，不当作某次已发生的事 |
| 我的判断 | 助手的合理起点可能是整理名单并讲清依据 | 写明是自己的判断 |
| 待核项 | 80 万和 120 万各自怎么算 | 写下一步找谁、要什么依据 |

## 五、访谈老周、陈姐时怎样用

这里不列问题，先自己想清楚三件事：

1. 这个人的职责决定了他能回答什么，什么不该问他。
2. 这次要拿回哪一个具体认识，它能帮上哪一个还没解决的判断。
3. 他最近经手的一件具体的事是什么，能不能请他从头讲一遍。

想清楚再开始，问法参考第二节，方法细节回看 V02。
