## 二、逐条分析

### #1 复购率统计口径 → GAP-003(口径确认),服务 GAP-001

- **为什么必须问**:验收要可测量,现状和回升必须用同一个算法——时间窗(多久算一次)、参照期(跟哪段比)、当前幅度。
- **建议问法**(口语版,与清单 §2 一致;**直接问「怎么算的」,不替他给二选一**):「沈总,复购率这个数,你们现在是怎么算的?——多久之内又来买,算他复购一次?」
- **参照期、当前幅度不挤进同一条**(2026-10-24 拍板:一条消息问一堆真人记不住)→ E2:答了窗缺参照就问「跟下滑之前比,拿哪个季度当参照」;答不出→给缺省授权(季度复购、参照取下滑前那个季度,数字等 W2 老周核完校准)。
- 「80 万活跃」的定义**不在这问**(2026-10-24 九轮:它是圈人范围口径,不是验收指标)→ 挪清单 §4,见 #4。对应 T3(§2);T4/T6(E2)。

### #2 三个月验收目标未明确 → GAP-002 核心(时间窗)

- **唯一只有沈总能答的题**:硬线是什么(他的成功定义)、目标值多少、未达标算延期还是失败。
- **建议问法**(2026-10-24 三修定稿,**直接问、不摆选项、不绕**,与清单 §1 一致):「沈总,咱们直接点:这个项目,您的验收标准是什么?——就是三个月后,做到什么样,您认为这事就成了?最好有个数。」「差一点算延期还是失败」不问(2026-10-24 九轮拍板删:不是验收标准本身,见清单 §1)。
- **为什么不摆三候选**:目标是客户对董事会的业务承诺,选择题会①把归属变成「我们提的方案」②错过他心里不在选项里的真实答案③他随手挑最省事的。缺省确认只用于执行细节(算法/起算日),不用于目标本身。
- **答得虚**(「解决下滑就行」)→ E1 从**他的话**里长选项:「是回到之前的水平,还是先止住不掉就行?」
- **陷阱应对**(固定回答,不占条数):「这个数得您来定。我能给的是算法和数据,保证这数算得出来、对得上账。定低了没意思,定高了完不成,您也没法交代——所以数您定,**算得出来**我来保。」
- 对应 T1。

### #3 会员老化口径未明确 → GAP-004

- **2026-10-24 八轮后**:不再「并入二选一」(原二选一已废,见 #5);清单 §4 **直接问定义**:「这个『老化』,您指的是什么样的会员?」
- 原判断「单问会变成病因学讨论」**作废**:问的不是病因是否成立,是**判别标准**(什么样的会员算老化)——答案直接进范围条款,不空转。
- 他给不出 → 缺省建议(「第一版先按复购掉得最厉害的挑」,标明我建议请他批)+ W2 老周核数据后给操作化定义。病因是否有数据依据(V2)随之核或伪。

### #4 活跃会员定义未明确 → GAP-003(口径确认)+ GAP-004(圈人定义域)

- 沈总邮件引用了 80 万这个数,他至少知道出处——「活跃」按什么定的。
- **⚠️ 不预设「活跃=有消费」**(2026-10-24 拍板):问「是多长时间以内**买过东西**算的」等于替他把口径设成了消费行为——他的活跃可能是到店、开卡、App 打开。定义必须他给。
- **清单 §4 第一问**(2026-10-24 九轮:目的=从活跃会员里筛重点经营对象,「活跃」是筛选的定义域,与「老化」同属圈人口径,从原 §2 挪来):「邮件里说的 80 万活跃——这个『活跃』,你们是怎么定的?」他答了定义没带窗口,顺势接「多长时间以内算?」(现场口语,不占独立条)。
- 答不出→缺省授权+W2 老周核。对应 T5(定义+窗口,§4)。

### #5 识别重点经营会员的规则 → GAP-004 核心

- **拆两半**:沈总定**口径**——「活跃」+「老化」两个定义(§4 两问,第一版名单从活跃会员里按老化口径筛,试点框架在 §5 复述确认);**规则细节(阈值、权重、新老划分)是老周的活,W2 核**。
- ⚠️ **没有「店」**(七轮拍板):邮件语境业务对象是会员人群,门店维度已删。试点规模(圈多少人)= 执行细节,W2 给数请确认。
- ⚠️ **「消费掉得厉害」删**(八轮拍板):客户只说了「复购下滑」——复购是频率指标,≠消费下降,换词=脑补。「复购掉得最厉害」只能作为**我们的缺省建议**标明提出,不冒充客户选项。
- **谁复核谁执行 → E3** 一句锁(顺带锁定「到人工为止」边界)。
- 向沈总要完整规则他会答不了还占条数。对应 T9 + T10(E3)。

### #6 产品要给运营一套表(含建议)?→ GAP-006

- **方向先纠正**:沈总邮件原话是「**别又**让她多整理一套表」——客户约束恰恰是**不要新增表**,建议要进小林现有工作流。
- **谁答**:主体在小林(W2 问:她现在用什么表/系统、建议以什么形态送达才不算"多一套表");沈总层面只锁**边界一句话** → E3:「系统出名单和建议,小林复核完人工去执行——系统不直接发券。」
- 对应 T10 / E3。

### #7 上个智能营销项目为何没做好 → 风险 R3(不在 fit-gap 条目内)

- **问法关键(2026-10-24 去追责化)**:不问「为什么没做好」(归因叙事),也不问「怎么算『没做成』的?标准谁定的?」(审计句式——「标准谁定的」指向人,像翻旧账查案)。「哪里没做好」可以直接问:沈总邮件自己就说这项目没做好,顺着他的话问事,不是替他定性。改为**指向事、带动机**(与清单 §3 一致):「之前那个智能营销的项目,这回咱们把上次的坑绕开——您觉得当时主要是哪里没做好?」
- 他说完卡点顺势接(现场口语,不占独立条):「那当时收尾的时候,验收是怎么走的?有定过什么标准吗?」
- 答案直接决定这次验收设计:没定过标准→这次标准要更硬;执行垮了→这次要复核机制。
- 「供应商没交付好」是单方归因,不反驳不附和,记 reported。对应 T7。

### #8 对方能提供什么数据 → GAP-004 前提(R4)

- **降级为授权问题**:沈总大概率不知道表结构和接口,直接问他≈得到一句「老周知道」,白占一条。
- **向沈总只问**(口语版,与清单 §5 收尾一致):「下周我约老周核核数据、找小林看看他们怎么干活——您安排,还是我直接约?另外这项目往下走还是停,最后谁说了算?」(T12)。
- 数据清单本身由老周 W2 出。这也是邮件第 3 段的分工:「系统情况找老周」。
