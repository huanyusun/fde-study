# W02 候选场景：会员运营待关注名单与依据整理

> v1｜2026-11-02。性质：**我方建议**，依据 W2 五人第一轮访谈（小林 10/12、陈姐 7/12、老周 8/12、王经理 3/12、沈总 4/12）整理，**需回访确认后才可进入业务模型**。所有引用均为角色陈述，不等于已核实事实；MSG 编号可回查 [原始记录](interview_transcript.md) 与 `artifacts/w02/sources/*.json`。

## 一句话

把小林"人工翻任务＋手工 Excel 整理名单、逐条找人对信息"的做法，改为系统给出**待关注会员候选名单＋逐条依据**，由业务人员确认后转门店执行；全程不自动执行任何动作。

## 六要素

### 1. 为谁解决什么问题

| 谁 | 问题 | 依据 |
| --- | --- | --- |
| 小林（主用户） | 整理名单和执行记录、找同事确认对不上的信息、反复跟进进度最费劲；系统不是主要抓手，实际靠手工 Excel | MSG-02934、02939 |
| 陈姐（连带用户） | 活动要求不清楚，门店一边接待顾客一边来回找人确认；希望适用范围、门店要做的事、问题找谁提前说清 | MSG-02957、02962 |
| 沈总（目标层） | 项目要服务于复购率止跌回升这一核心问题 | MSG-02995 |

边界（客户原话）：小林明确不授权自动发券、联系会员、改记录（MSG-02947）；人群和执行方案最终由业务人员确认（MSG-02943、02947）。

### 2. 输入是什么（均为候选，实物均未取得）

| 输入 | 现状 | 依据 |
| --- | --- | --- |
| 没做完的运营任务和反馈 | 小林描述的活动起点，无实物 | MSG-02935 |
| 会员记录 | 120 万为系统**全量**会员数≠活跃会员数；会员分付费会员卡／免费注册；订单分线上／门店；券分发放／核销 | MSG-02973、02985（老周复述确认） |
| 会员标签字段 | 系统有字段，含义与维护人未核实 | MSG-02975 |
| 现用 Excel | 小林确认存在、绕开系统使用；具体内容未提供，未答应脱敏导出 | MSG-02937、02953 |
| 活动三要素 | 面向哪些会员、哪些门店参与、门店具体做什么——陈姐的执行前置核对项 | MSG-02956、02968 |

### 3. 产出是什么

- **待关注会员候选名单**，每条附依据：为什么把这位会员列进来、依据哪些情况（小林原话要求，MSG-02949）。
- 每条建议随附**执行说明字段**（我方组合，回应陈姐）：会员口径标注（全量／活跃、付费／免费）、适用门店范围、门店要做什么、现场问题找谁（MSG-02956、02960）。
- **不做**：自动发券、联系会员、改记录；不替代业务人员确认；金额和指标未定的一律标"待确认"（王经理 MSG-02989、02993）。

### 4. 谁执行

| 环节 | 谁 | 依据 |
| --- | --- | --- |
| 出候选名单＋依据 | 系统（建议）；小林照依据整理 | MSG-02947、02949 |
| 人群与方案确认 | 业务人员（小林明确"不是我说了算"） | MSG-02943 |
| 门店适用范围核对与执行 | 陈姐及门店同事；反馈对接小林 | MSG-02956、02959 |
| 数据口径核对 | 老周牵头、小林运营侧配合、项目组共同核实；沈总不替部门裁定 | MSG-02997 |
| 财务核查 | 王经理可提核查意见、要求补充、暂缓财务确认；不能替公司承诺审批 | MSG-02989 |

### 5. 如何观察效果

| 层 | 观察点 | 现状 |
| --- | --- | --- |
| 小林 | 重复整理与核对的次数是否减少 | 仅本人感受，未量化（MSG-02939）——需先约定观察方式 |
| 陈姐 | 活动要求澄清往返是否减少 | 未量化（MSG-02962） |
| 项目 | 复购率止跌回升 | 口径未定（沈总 MSG-02995），须先由老周牵头定口径才能观察；三个月阶段进展是期望非验收硬线（MSG-02999） |
| 财务 | 效果须与费用对应、可量化、留记录 | 效果记录方案本身是待补材料（王经理 MSG-02989、02993） |
